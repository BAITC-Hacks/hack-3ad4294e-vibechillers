**S01, оба режима, F003 + F018.** До: 3.1 — «ООЗ регистрирует все входящие заявки
клиентов в едином журнале заявок» (block 16). После: 4.1 — та же регистрация у ЦРЗ

категориям клиентов или этапам обработки не установлено». Преемство ООЗ → ЦРЗ
прямо установлено 2.2. Report оставляет changed к одному получателю и added без
подтверждённого предшественника ко второму. Предварительный frozen label ожидает
полный duplicate `before:3.1 → after:4.1 + after:10.1`. Верный отдельный
`R00742d711177` делает пересечение видимым, но не исправляет function lineage.

**S02, оба режима, F004/F005/F006/F008.** Действия сохранились, поменялись
наименование владельца и номер пункта:

## Поддержанные выводы и разногласия

F002 верно отмечает ежегодную проверку сроков хранения before 2.2: никакого
преемника нет во всём supplied after при явной полноте комплекта 11.1. F001
правильно сохраняет реестр и ежемесячную сверку `before:2.1 → after:3.1`.

предшественники объявлялись потерянными вопреки таблице подразделений.

`R00742d711177` верно связывает две регистрации всех заявок; `R1573e6f06e8c`
верно связывает выбор поставщика 7.2 и проверку собственного выбора 7.4 одним ЦС.
Фраза «Внешнее согласование такого заключения не требуется» усиливает основание
потенциального self-control риска. Вывод advisory, без вымышленного нарушения
закона. Риск с одной unit здесь корректен: исполняющий и проверяющий субъект один.

Отрицательный пример after 8.1/9.1 сохранён: ОФК согласует финансовую часть
исключительно в пределах бюджета и исключён из технической; ОТП разрабатывает
техническую часть и не распоряжается бюджетом. На этих refs нет ни одного риска
обоих типов, при наличии двух положительных рисков на других refs. Это
поддерживает данный один negative, не общую specificity продукта.

**F009 — единственное изменение агента.** Deterministic оставляет unresolved
`before:7.1 → after:7.4 + after:2.6`; agent даёт changed с `review_required=true`.
Это содержательно поддержано: независимая проверка ОФК стала проверкой ЦС
собственной работы, а 2.6 прямо устанавливает передачу. При этом 2.6 —
распорядительный контекст передачи, включённый в after-set наравне с самой
обязанностью 7.4; разделение duty/context остаётся ограничением детализации.
Generic reason агента не объясняет потерю независимости, хотя точные цитаты
позволяют это увидеть. Этот случай вне frozen function labels: изменение
содержательное, но не новый TP и не улучшение frozen-метрик. Unresolved изменилось
с 1 finding / 3 refs до 0 / 0; это не само по себе доказательство точности.

Для F010/F011 сохраняется альтернативная трактовка разметки: changed из-за новых
явных отрицательных границ либо moved, если считать добавления уточнением уже
исключительной компетенции. Существующие pending-human labels остаются changed;
это не новая adjudication и не ретроспективное изменение gold.
