# Stage 3 — execution prompts

Run each prompt in the named participant's **main coding session** using **GPT-6 Astra / high / fast 1.5×**. All three workstreams start concurrently after receiving the handoff commit. Only Batyrkhan has configured OMP agents/provider routes; Alibi and Askat use their available Codex environment, without requiring subagents or personal API credentials. These prompts implement [the active plan](stage-3.md); they do not reopen Stage 1/2. The ownership cutover is explicit: **Batyrkhan = backend/contracts/dependencies; Alibi = eval/fixtures/quality; Askat = frontend/export/delivery**.
